# Plain Insight

## What is this project?

Plain Insight is a conversational quant engine that helps users turn natural-language investment ideas into strategy filters, backtests, and paper trading workflows.

## Why did I build it?

I built this project to make strategy creation easier for users who have investment ideas but do not want to write complex code or manually test every condition.

## What features does it have?

* It converts natural-language ideas into structured strategy conditions.
* It provides stock filters, buy strategy filters, and sell strategy filters.
* It runs backtests and shows key results such as return, win rate, drawdown, and risk.
* It visualizes portfolio performance and current asset allocation.
* It supports paper trading before any real trading execution.

## How do you use it?

1. Enter an investment idea in natural language.
2. Review and adjust the generated strategy filters.
3. Run a backtest to check performance.
4. Save the strategy or test it in paper trading mode.

## Future plans

I plan to improve the strategy builder, add more market data sources, enhance AI-assisted strategy suggestions, and build safer live-trading gate controls.
